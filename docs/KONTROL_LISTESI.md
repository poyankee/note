# Note — Kontrol listesi

Tablette sırayla deneyin. Çalışanın yanına ✅, sorunlunun yanına ❌ ve kısa not yazın; listeyi bana geri gönderin.
Kurulum: GitHub › Releases › en yeni **Note sürüm N** › `Note-N.apk` (eski sürümün üzerine kurulur, defterler silinmez).

## 0. İlk açılış
- [ ] İlk açılışta 5 sayfalık kısa tanıtım (Geç / İleri / Başla); Ayarlar › Hakkında › Tanıtımı göster ile tekrar açılıyor

## 1. Ana sayfa
- [ ] Solda sade bir şerit: büyük **+** düğmesi, Defterler, Yanlış defteri, Yapılacaklar, Çöp kutusu, Ayarlar (küçük ekranda da kayıyor)
- [ ] **+** menüsü: Yeni defter, Hızlı not, PDF aç, Fotoğraflardan defter, Şablondan yeni defter, Yeni klasör
- [ ] **Yeni defter** ad sormadan düz beyaz açılıyor; geri dönünce "Kaydedildi" bildirimi
- [ ] Hızlı not: ana ekranda uygulama simgesine uzun basınca da var
- [ ] **Klasörler defterlerin üstünde sekme**: Tümü, ★ Favoriler, klasörler, "Klasör" ile yeni klasör; klasör sekmesine uzun bas → Yeniden adlandır / Renk / Sil
- [ ] Görünüm (▦): küçük / orta / büyük kapak / liste
- [ ] Sıralama: son düzenlenen / ada göre / oluşturma tarihi
- [ ] Arama kutusu
- [ ] **Seç** (veya deftere uzun bas): toplu seçim → Tümünü seç, Favori, Klasöre taşı, Sil, **Birleştir** (2+ defter)
- [ ] Defter ⋯ menüsü: Aç, Seç, Yeniden adlandır, Klasöre taşı, Favori, Kilitle, **Şablon olarak kaydet**, Sil
- [ ] **Yanlış defteri** (sol şerit) açılıyor
- [ ] **Yapılacaklar** (sol şerit): görev ekle, dokununca tamamlandı, ⋮ renk / sıra / sil, "Tamamlananları temizle"
- [ ] **Çöp kutusu**: silinen defter burada; Geri getir; Kalıcı sil; Boşalt
- [ ] **Şablondan yeni defter**: kaydettiğiniz şablon listede, seçince yeni defter açılıyor
- [ ] **Fotoğraflardan defter**: birkaç fotoğraf seç → her biri bir sayfa

## 2. Defter kilidi
- [ ] ⋯ › Kilitle → PIN (iki kez) → kapakta kilit
- [ ] Açarken PIN soruyor; yanlış PIN 5 kez → bekleme süresi
- [ ] **PIN'i unuttum** → cihazın ekran kilidi (desen/PIN/parmak izi) → kilit kalkıyor

## 3. Kalem ve el
- [ ] Sadece kalem yazıyor, el/avuç yazmıyor
- [ ] Ayarlar › Kalem ve el: avuç boyutu ve bekleme süresi ayarları
- [ ] **Kalem testi**: yazınca, yan tuşa basınca, çift dokununca sağda satırlar çıkıyor mu? (Ekran görüntüsünü bana gönderin)
- [ ] Tuşu öğret (çift dokunuş algılanırsa)
- [ ] İki parmakla dokunma = geri al
- [ ] İki parmakla yakınlaştırma / kaydırma
- [ ] Ayarlar › Yazı: basınç, **basınç eğrisi**, yumuşatma, tahmin, silgiden otomatik dönüş, otomatik yeni sayfa, yakınlaştırma kilidi

## 4. Araçlar (üstteki şerit)
- [ ] Araçlar üst çubuğun ortasında yatay şerit; seçili aracın renk / kalınlık / kayıtlı kalemleri hemen altında ince bir şeritte
- [ ] Seçili araca tekrar dokununca alttaki seçenek şeridi gizleniyor / açılıyor
- [ ] Ayarlar › Görünüm › **Araç çubuğu: Solda yüzen menü** seçilince eski sol menü geri geliyor
- [ ] Kalem, fosforlu, silgi (bütün / kısmi), seçim, geometri, metin, lazer, geçici kalem
- [ ] **Seçili araca tekrar dokununca** seçenek penceresi: renkler, kalınlık, kayıtlı kalemler, ✎ renkleri düzenle
- [ ] Silgi seçenekleri: boyut, kısmi, "Sildikten sonra kaleme dön", Sayfayı temizle
- [ ] Menü daralt (˄): kalem + silgi görünüyor
- [ ] Menüyü ⠿ tutamaktan taşıma; ekran dışına çıkmıyor
- [ ] Geometri: şekil, doğru, ok, çokgen, pergel, işaret, 3B; seçenekler (kesikli, dolgu, harfler, ölçüler)
- [ ] Çizip bekle → düzgün şekil
- [ ] Cetvel, gönyeler (45° ve 30°-60°), iletki (Cetvel menüsü)
- [ ] Ders menüsü: spot ışığı, perde, sayaç

## 5. Seçim
- [ ] Kement ile seç → taşı, büyüt (sağ alt), döndür (üst)
- [ ] Alt çubuk: Kopyala, Kes, Çoğalt, Doldur, **Ölçü**, **Kutu**, **Kütüphaneye**, Sil, **renkler**
- [ ] Tek şekil seçince köşeleri sürükleme
- [ ] **Hareketli geometri**: üçgen/dörtgen seçiliyken kenar (cm), açılar (°), alan ve çevre görünüyor; köşe sürüklenince değişiyor
- [ ] **Kutu**: seçili yazıyı Kural / Tanım / Örnek / Dikkat / Formül / Özet kutusuna alıyor
- [ ] **Bağlı oklar**: Kütüphane › Genel › Kavram haritası ekleyin; bir kutuyu seçip taşıyın → ona bağlı ok da uzayıp kısalarak takip ediyor
- [ ] ⋮ › **Konu özeti oluştur**: bütün kutular sona eklenen "Konu özeti" sayfasında

## 6. Sayfa
- [ ] **Aşağı kaydırınca üst çubuk gizleniyor**, yukarı çekince geri geliyor (Ayarlar › Yazı'dan kapatılabilir)
- [ ] **Sayfa** paneli: desenler (kareli, izometrik, koordinat, birim çember…), görünürlük, aralık
- [ ] Kağıt rengi + **Diğer** (özel renk)
- [ ] **Masa rengi**
- [ ] **Sayfa boyutu**: A4 dikey/yatay, 16:9, **Tam ekran**
- [ ] Resimden / PDF'ten desen
- [ ] "Tüm sayfalara uygula"
- [ ] + Sayfa: yeni sayfa düz beyaz
- [ ] Son sayfanın altına yazınca otomatik yeni sayfa
- [ ] Sağ kenarda **sayfa çubuğu** (kaydırınca çıkıyor, sürükleyince sayfa no)
- [ ] Sayfa gezgini: ‹ ›, "sayfaya git", sayfalar paneli
- [ ] Sayfalar paneli: uzun bas → çoğalt, sil, taşı, döndür, kırp
- [ ] Sayfalar paneli › uzun bas › **Taşı (yeni yerine dokun)**: sayfa dokunduğunuz yere gidiyor
- [ ] Sayfalar paneli › **Seç**: birden çok sayfa → Döndür, Çoğalt, Sil, Ayrı deftere çıkar
- [ ] ⋮ › Sayfaya sığdır, Yakınlaştırma kilidi, Sayfayı döndür
- [ ] Kaldığın sayfadan açılma
- [ ] Ayarlar › Sayfalar › **Sayfa altında**: sayfa no / sayfa no + tarih

## 7. PDF
- [ ] PDF üzerine yazma, keskin görüntü (yakınlaştırınca)
- [ ] Sayfaya git (kitap sayfa numarası ile)
- [ ] Yer imleri ve PDF içindekiler
- [ ] PDF sayfasını döndür / kırp
- [ ] ⊕ › **Başka PDF'ten sayfa ekle**
- [ ] ⋮ › **Sayfaları ayrı deftere çıkar** ("3-7, 12")
- [ ] ⋮ › **Defterde ara** (metin, formül, PDF yazısı)
- [ ] **PDF yazısını vurgulama**: PDF'te fosforlu kalemle bir satırın üzerinden geçin → çizgi, metin satırına oturan düzgün bir vurguya dönüşüyor (Ayarlar › Yazı'dan kapatılabilir)

## 8. Ekle (⊕)
- [ ] Görsel, fotoğraf çek
- [ ] Formül (canlı önizleme), formüle metin aracıyla dokununca düzenleme
- [ ] Fonksiyon grafiği
- [ ] **Değer tablosundan grafik** (Doldur ile fonksiyondan)
- [ ] Yapışkan not, damgalar
- [ ] **Hazır kütüphane** (üst çubukta da simgesi var): kategoriler, arama, kesir modelleri (pay/payda), Benim çizimlerim
- [ ] **Soruyu yanlış defterine ekle** → dikdörtgen içine al → yanlış defterinde yeni sayfa; orada **Kaynağa git**
- [ ] Yanlış defterinde üst çubuk: **Konu ekle**, **☐ Çözüldü**, **Tekrar modu** (çözüm alanına yazdıklarınız gizlenir), **Sorular ▾** (konuya / çözülmeyenlere göre süz, soruya git)

## 9. Ders anlatımı
- [ ] **Odak modu** (üstte tam ekran simgesi): sadece küçük panel; sağ/sol kenara götürünce dikey
- [ ] Projeksiyon / HDMI: harici ekranda yalnız sayfa
- [ ] Lazer, geçici kalem, spot, perde, sayaç
- [ ] **Çözüm katmanı**: Ayarlar › Sayfalar › Çözüm rengi (ör. kırmızı) → ⋮ › Çözümleri gizle / göster
- [ ] Ders kaydı (beklemede; çalışıyor mu bakmanız yeterli)

## 10. Dışa aktarma ve yazdırma
- [ ] Paylaş: tüm defter PDF, bu sayfa PDF, bu sayfa PNG
- [ ] Dışa aktarırken **Çözümleri gizle (soru kağıdı)** ve **Sayfa numarası**
- [ ] **Küçük dosya (sıkıştır)**: büyük bir PDF'i bununla dışa aktarın, dosya boyutu küçülüyor
- [ ] ⋮ › **Yazdır**

## 11. Ayarlar
- [ ] **Arayüz stili**: Sade / Canlı / Koyu (önizlemeli); hem ana sayfa hem defter değişiyor
- [ ] **Dil / Language**: English seçince uygulama yeniden açılıyor ve menüler İngilizce; Türkçe ile geri dönüyor
- [ ] Tema: sistem / açık / koyu; **Renk teması** (Okyanus, Orman, Gün batımı, Kağıt, Gece, Yüksek kontrast)
- [ ] **Arayüz boyutu** (Küçük … Çok büyük = erişilebilirlik)
- [ ] **Göz dostu mod**
- [ ] Solak kullanım, panelleri sıfırla
- [ ] Yedekleme: Şimdi yedekle, Yedekten geri yükle (ayarlar da geri gelir; uygulamayı yeniden açın), otomatik yedek klasörü
- [ ] **Depolama**: boyutlar, geçici dosyaları sil, kullanılmayan görselleri sil
- [ ] **Hata kayıtları**: (varsa) paylaş / sil
- [ ] **Hakkında**: sürüm, Gizlilik politikası, Sorun bildir, Açık kaynak lisansları

## 12. Klavye (bağlıysa)
